# Sleep Log（睡眠記録）

個人用の睡眠記録Webアプリ。夜間睡眠・昼寝・意図しない寝落ちを、いつでも何回でも事後入力できることを最優先にする。

## 現在の状態

2026-10-18：第1段階のアプリ、DB定義、GitHub Pages用ワークフローを実装した。Supabaseのプロジェクトは未作成のため、実際のクラウド接続とWeb公開は未設定。

接続情報がない場合は、架空データによる体験モードを利用できる。体験モードの変更は本番の記録にはならない。

配置先は `/home/wsl/projects/apps/sleep-log`。`My-Mini-Games`、`circle-scheduler` と同じ階層。

## 起動

Node.js 22以上を使う。

```bash
cd /home/wsl/projects/apps/sleep-log
npm ci
npm run dev
```

`http://localhost:3000/` を開く。クラウド未設定なら「画面を体験する」で操作を確認できる。

実際のログイン・クラウド保存・公開の設定は [SETUP.md](SETUP.md) を参照。Supabaseの有料プランへの変更は行わない。

## 実装した機能

- 日本時間による睡眠の追加・編集・削除、1日に複数回、日付またぎ、長時間睡眠。
- 種類、意図、開始・終了それぞれの推定、メモの入力。
- 日別一覧、記録合計、月間カレンダー。
- GitHubログインと本人の利用許可、クラウド保存への接続処理。
- DBでも行う重複・不正日時の拒否、同時編集の保護、保存再試行の二重登録防止。
- 同じタブでの未保存入力の一時退避。
- 全件JSONバックアップ、不足分だけを追加する原子的な復元。
- PC・スマートフォン幅の表示、GitHub Pagesへの静的書き出し。

## ユーザーが示した要件

### 目的と重要な前提

- 睡眠状況を記録・可視化し、必要に応じて医師に説明できるようにする。
- 睡眠障害の診断は行わない。
- 1日1回という制限を設けず、すべての睡眠を同じ構造で管理する。
- 寝落ちを後から簡単に記録できる操作を最優先にする。
- 6時間を超える寝落ち、12時間以上の睡眠、日付をまたぐ睡眠を扱う。
- 開始時刻が不明な場合は、推定時刻で登録できる。

### 記録する情報

- 睡眠開始日時・終了日時
- 種類：通常睡眠・昼寝・寝落ち・その他
- 意図的だったか、意図しなかったか
- 時刻が正確か、推定か
- 任意のメモ

開始・終了日時から時間を自動計算し、過去の記録も追加・編集・削除できるようにする。

### 第1段階：基本的な記録

- 睡眠の追加・編集・削除
- 同じ日に複数回の睡眠を登録
- 日付をまたぐ睡眠への対応
- データの永続保存
- 月間カレンダーと、日付を選択したときの記録一覧・編集
- 各日に実際に眠っていた時間を配分した日別合計。二重計上しない

### 第2段階：可視化・分析

- 種類別の色を使う24時間タイムライン。日付をまたぐ記録のつながりも分かる表示
- 日別の睡眠時間と推移のグラフ
- 週間・月間平均、通常睡眠と昼寝・寝落ちの時間の集計
- 睡眠開始・起床時刻の推移、寝落ちの回数・時間帯、種類別の割合

### 第3段階：追加機能

- 起床時の状態：すっきり・普通・眠い・非常に起きづらい
- アラームを何度も止めたこと、二度寝の記録
- 日中の眠気の強さと時間帯の記録
- CSV出力、印刷・PDF出力、直近2週間の睡眠日誌
- PWAによるホーム画面からの起動
- 任意の睡眠開始・終了タイマー。手動の事後入力を引き続き優先する

### UI・技術の希望

- iPhoneを中心に、PCでも使えるレスポンシブな画面
- 少ない操作で入力でき、日時を入力しやすいこと
- カレンダーやタイムラインから編集できること
- 通常睡眠は青、昼寝は緑、寝落ちはオレンジを候補にする
- Next.js / TypeScript / React / Tailwind CSSが技術候補
- 個人情報の保護に配慮し、保存方法とアカウント管理の範囲を相談する
- コードの保管にGitHubを使い、Web公開にもGitHub Pagesを使いたい（2026-10-18に確認）

## 決定した初期仕様

- GitHubでコード管理、GitHub PagesでWeb公開、Supabase Freeでクラウド保存する。
- GitHubアカウントでログインし、本人だけが記録にアクセスできるようにする。
- バックアップの書き出し・復元を第1段階に含める。
- 1回の睡眠を1件とし、開始・終了それぞれに推定の属性を持つ。
- 日付またぎは日本時間0:00で各日に配分し、重複保存を拒否する。
- 未記録日を睡眠0時間とみなさない。
